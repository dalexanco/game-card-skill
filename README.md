# game-card-skill

Agent skill to design a card game and generate printable A4 card sheets.

## Install

```bash
npx skills add dalexanco/game-card-skill
```

## Skills

| Skill | Description |
| --- | --- |
| [`print-and-play-cards`](skills/print-and-play-cards/SKILL.md) | Design a card game end to end and produce printable A4 sheets (cards, backs, rules sheet). |
